# 《話外之協》影展專題官方網站 - Vibe Coding 指令與 Prompt 說明記錄

本文件為 115-1 商學院行銷系「數位行銷程式設計基礎」Project 1 上機考作業之 **AI 輔助開發（Vibe Coding）Prompt 說明記錄**。

---

## 專案基本資訊
* **專題名稱**：影展專題《話外之協》官方網站
* **核心標語 (Slogan)**：走出話裡的想像，看見話外的東協
* **組別**：甲六
* **指導老師**：丁美靜 老師、李悅端 老師、王婉禎 老師、李律鋒 老師
* **團隊成員**：曾宇婕、陳以芊、康庭瑀、張漢羽、楊昕恩、翁湘羚、妮塔、王上偉
* **官方影片連結**：[YouTube 完整微電影觀賞](https://youtu.be/mYIyYKoyNw0)
* **主題意涵**：打破大眾對台中東協廣場的刻板印象，以青年視角與文化共融短片促成跨族群理解。
* **技術規格**：HTML5 語意標籤、CSS Grid 系統、RWD 響應式切版、CSS 模組切割（`style.css`, `grid.css`, `components.css`）、SEO Meta 標籤優化、多平台雲端部署。

---

## Vibe Coding Prompt 對話指令集記錄

### 階段一：專案架構與規範建置
> **提示詞（Prompt 1）**：
> 「我們正在進行數位行銷程式設計基礎的影展專題上機考。我們的主題是打破大眾對台中東協廣場的刻板印象，專題名稱為《話外之協》，Slogan 為『走出話裡的想像，看見話外的東協』。請依照老師的作業規範，為我們規劃出具有頂端導覽列、側邊欄、分頁結構、RWD 手機版適配、SEO 標籤，以及嚴格將 CSS 切割在 `css/` 資料夾、圖片放 `images/` 資料夾的完整網站架構。」

* **AI 輸出回饋與落實**：
  * 規劃 4 大核心分頁：首頁 (`index.html`)、企劃理念與 STP (`about.html`)、影片放映室 (`gallery.html`)、團隊成員分工 (`team.html`)。
  * 嚴格規範 CSS 拆分為：`style.css`、`grid.css`、`components.css`。

---

### 階段二：UI 風格重構與手作拼貼調研
> **提示詞（Prompt 2）**：
> 「整體的 UI 風格不要老氣的漸層色。請將整體配色改為溫柔的莫蘭迪薄荷綠與暖可可咖啡色，底色換成有溫度如手寫手揉紙質感的米白色，並加入紙膠帶（Washi Tape）等拼貼元素；側邊欄要精確對齊跳轉標題，刪除所有 emoji 表情符號與多餘資訊卡。」

* **AI 輸出回饋與落實**：
  * 配色重構：以溫柔莫蘭迪薄荷綠 (`#6b9080`) 與深焙可可棕 (`#4a3b32`) 為基調，搭配細膩手作紙纖維底色 (`#f6f2ea`) 與半透明紙膠帶拼貼。
  * 修復滾動邊距：設定 `scroll-padding-top: 96px;` 與 `scroll-margin-top: 96px;`，確保側邊欄點擊完美對齊。

---

### 階段三：行銷企劃 STP 與受眾洞察融入
> **提示詞（Prompt 3）**：
> 「請將我們企劃書中的核心 STP 與訪談洞察自然轉化入網頁，不要死板照抄，並刪除『伍陸柒』章節序號：
> 1. 市場區隔 (Segmentation)：以台灣在地民眾為核心溝通對象。
> 2. 目標受眾 (Targeting)：鎖定 20-35 歲青年世代，融入林同學（20歲大學生）與邱小姐（35歲上班族）的 Persona 訪談。
> 3. 市場定位 (Positioning)：以『文化體驗 × 多元生活』為定位方向，對接『走出話裡的想像，看見話外的東協』。」

* **AI 輸出回饋與落實**：
  * 精修 STP 文案，採用 CSS Grid 結構化排版，呈現學術與市場實務兼具的數位行銷深度。

---

### 階段四：團隊分工精簡與正式影片嵌入
> **提示詞（Prompt 4）**：
> 「團隊分工每個人的簡述精簡至一句話精華。將我們的正式影片連結 https://youtu.be/mYIyYKoyNw0 嵌入放映室的 16:9 自適應外框中。」

* **AI 輸出回饋與落實**：
  * 8 位成員心得精簡為 15～25 字的核心職責與心得。
  * 於 `gallery.html` 成功嵌入 YouTube 16:9 高畫質播放器。

---

* **AI 輸出回饋與落實**：

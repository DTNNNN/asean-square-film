## 專案簡介
本專案為行銷二甲影展專題網站《話外之協》，以台中「東協廣場」為核心主題。透過紀實短片故事、實地街訪以及行銷 STP 策略分析，打破大眾對東協廣場的刻板標籤，展現文化共融的真實日常。
